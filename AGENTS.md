# Global instructions

code should never contain comments

Execution over explanation:
If the request implies a code change, perform the change in the workspace first.
Do not stop after presenting the code or describing the changes.

The following does NOT count as completing the task:

- showing a code snippet;
- describing a patch;
- saying "I will change...";
- providing a replacement file in the chat.

The task is complete only after the requested changes have been applied to the files.

## Response Style

Keep responses concise and direct.

- Give only relevant information.
- Do not repeat the request or unchanged code.
- For implementation tasks, modify the files directly. Showing code in chat is not a substitute.
- Consider the task incomplete until the requested file changes are actually applied.
- After changes, briefly state what changed and whether it was validated.
- Do not ask unnecessary questions.
